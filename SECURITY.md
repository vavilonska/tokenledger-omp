# Security Policy

## Supported source

Security maintenance applies to the current TokenLedger OMP source in
[the public repository](https://github.com/vavilonska/tokenledger-omp).
Report the affected release version or local build commit.
Do not use the upstream project's release or security-reporting page for this fork.

## Reporting a vulnerability

Do not open a public issue or include sensitive details in a repository issue. Contact the
TokenLedger OMP repository owner through an existing private collaborator channel and agree on a
confidential way to share the report. No dedicated security mailbox or private advisory service
has been configured for this fork.

Include:

- The affected TokenLedger OMP version, commit, and operating system
- A description of the vulnerability and its impact
- Reproduction steps or a proof of concept when available
- Any suggested mitigation

Do not include real credentials, access tokens, or private account data. Coordinate a fix or
mitigation privately before disclosing details.
